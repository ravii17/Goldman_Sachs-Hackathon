## Goldman Sachs Hackathon 2026 — Problem Statement 1

# Problem Overview

This project builds a fully deterministic JSON schema inference engine capable of:

* Parsing large JSON datasets
* Inferring TypeScript interfaces
* Resolving nested object structures
* Handling unions and optional fields
* Generating collision-free interface names
* Producing character-perfect output

The generated output must exactly match the expected result, including:

* Whitespace
* Ordering
* Newlines
* Formatting
* Lexicographical sorting

# Deterministic Naming Engine

Interface names are generated using:

InterfaceName = key[0].toUpperCase() + key.slice(1)

Collision handling:

* Address
* Address2
* Address3
* ...

ensures globally unique interfaces.

---

# Type Merging Logic

The engine recursively merges all observed structures across records:

## Object Merge

MergedType = \bigcup_{objects} Keys(object)

## Union Construction

Types are combined using deterministic ASCII-sorted unions:

```ts id="qpkdlf"
number | string
```

```ts id="1yd0kg"
Address | null
```

```ts id="2vd2tb"
(boolean | null | number | string)[]
```
